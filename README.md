# Digital Store - Projeto Final Front-end

Aplicação web e-commerce desenvolvida em React com Vite como projeto final do módulo de Front-end[cite: 1].

## Funcionalidades
- **Home:** Carrossel de destaques, coleções e vitrine de produtos em alta.
- **Listagem de Produtos:** Catálogo completo com filtros e ordenação visual.
- **Detalhes do Produto:** Galeria interativa com miniaturas, seleção de tamanho/cor e produtos relacionados.

## Como rodar o projeto localmente
Siga os passos abaixo para executar a aplicação na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/fthiagom/digital-store-frontend.git](https://github.com/fthiagom/digital-store-frontend.git)

2.  Entre na pasta do projeto:
    cd src

3. Instale as dependências:
    npm install

4. Inicie o servidor de desenvolvimento:
    npm run dev

5. Acesse o site
    https://digital-store-frontend-theta.vercel.app/
